# URL人狼 v2

Render + GitHub用のサーバー版です。

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 空欄

## 追加機能
- 試合中の全プレイヤー生死一覧（生存／死亡）
- 試合に含まれる役職の一覧と、役職ごとの総人数・生存人数
- 人狼・恋人・双子・騎士団それぞれ専用の非公開チャット
- GM用の役職配置プリセット9種類（4人、5人、6人各種、7人各種）。ボタン1回で人数設定を適用・保存

## 今回の実装
- ルーム作成・URL参加
- GM権限
- 準備完了
- 4人以上でゲーム開始
- ランダム役職配布（基本構成）
- 昼・夜
- 投票
- 夜の能力処理（占い・護衛・罠・人狼襲撃・カウンセラー）
- 妖狐の襲撃耐性・占い死亡
- タフガイの1回耐える処理
- 双子・恋人の連鎖死亡
- 神様の役職表示
- 元の碧色デザインを維持

## 注意
ルーム情報はサーバーのメモリ上に保持しています。Renderの再起動・再デプロイをまたいでルームを永続化する仕様ではありません。
