# URL人狼

URLまたはルームIDを共有して参加できる、人狼ゲームの土台です。

## 必要なもの
- Node.js 18以上推奨

## 起動
```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 友達にURLで参加してもらう
このままでは自分のPC内だけで動きます。
インターネット上で公開する場合は、Node.jsを動かせるサーバーへ配置してください。
Render / Railway / Fly.io / VPSなどで公開できます。

公開後は
`https://あなたのドメイン/?room=ABC123`
のようなURLを共有できます。

## 現在入っている機能
- ルーム作成
- ルームID参加
- URLからルームIDを自動入力
- 最大20人の参加者表示
- 準備完了
- GM（ホスト）表示
- ゲーム開始
- 市民10役、人狼4役、第三陣営4役の詳細表示
